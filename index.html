             Raft Quorum Demonstration Guide:
          

          
    
            
  • Kill 1 Node: 2 nodes remain active $\implies$ Quorum ($2 \ge 2$) is maintained. If Leader is killed, Followers elect a new Leader. Transactions continue committing!
    • 
            
  • Kill 2 Nodes: Only 1 node remains active $\implies$ Quorum ($1 < 2$) is lost. The network halts gracefully to protect ledger consistency.
    • 
            
  • Revive Node: Node catches up on Raft logs, restoring quorum and unblocking consensus.
